# gamesnibi.github.io

Website for **Willow Pond Records** by NiBi Games, hosted free on GitHub Pages.

- Home: https://gamesnibi.github.io/
- Privacy policy (use this link in Google Play Console): https://gamesnibi.github.io/privacy.html

Plain HTML/CSS, no build step. Edit `index.html` or `privacy.html` and commit.
When the game adds online features, ads or purchases, update `privacy.html` (and its "Last updated" date) before releasing them.
