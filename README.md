# gamesnibi.github.io

The NiBi Games website, hosted free on GitHub Pages.

- Home: https://gamesnibi.github.io/
- Pond Reels privacy policy (use this link in Google Play Console): https://gamesnibi.github.io/privacy.html

Plain HTML/CSS, no build step. Edit `index.html` or `privacy.html` and commit.
When a game adds online features, ads or purchases, update `privacy.html` (and its "Last updated" date) before releasing them.
